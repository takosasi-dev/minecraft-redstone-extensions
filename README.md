# Minecraft 統合版(Redstone Extensions)

Minecraft 統合版(Bedrock Edition)のレッドストーン回路を広げるアドオン。
ワイヤレス送受信・床/壁/天井に貼れるワイヤー・論理回路・記憶素子・算術回路・センサー・調光ランプなど、
**ブロック 53 種・アイテム 6 種・クラフトレシピ 58 種**を追加する。

Mojang Studios / Microsoft とは関係のない、非公式のアドオンです。

- 名前空間 `wr:` / ビヘイビアパック `RedstoneExtBP` / リソースパック `RedstoneExtRP`
- 版 v1.31.3

---

## 主な機能

| 分類 | 中身 |
| --- | --- |
| ワイヤレス | 送信機・受信機・リモコン・チャンネル管理ブロック。名前(チャンネル)が同じものどうしで離れた場所へ信号を送る。チャンネルのカテゴリー分け・パスワード・一括の名前変更 |
| ワイヤー | 床・壁・天井の 6 面に貼れる多面ワイヤー。染料で 16 色に染められ、同じ色どうしだけが繋がる(並走できる)。発光モード。段差コーナーブロック |
| 計測・時間 | レッドストーン計測器(波形の記録)・パルス生成機(1〜2400 tick)・可変ディレイリピーター・非対称ディレイリピーター(ON と OFF で別の遅延)・即時リピーター・ワンショット・シーケンサー・クロックディバイダー・時刻トリガー・ランダマイザー |
| 論理回路 | NOT / AND / OR / XOR / NAND / NOR / XNOR・閾値ブロック(シュミットトリガー)・比較ブロック |
| 記憶・算術 | RS ラッチ・T フリップフロップ・レジスタ・定数電源・カウンター・加算回路・減算回路・数値表示ブロック(7 セグ) |
| センサー | エンティティセンサー・時刻センサー・天候センサー・コンテナ計測器 |
| 光源・建材 | 調光レッドストーンランプ・発光ブロック・隠し光源パネル・装飾建材 5 種 |
| 施錠 | 施錠ブロック・カードキー発行機・カードキー・アクセスログ |
| 機械 | 鉱石精錬機・XP タンク・ブロックディスペンサー・ホッパードロッパー・スパイク・ブロックブレイカー・サウンドブロック |
| 道具 | 配線レンチ・設定コピー機・ガイドブック(ゲーム内の説明、18 章) |

設定値を持つブロックは、右クリックで開くスライダーの画面で調整する。
サバイバルではクラフトで作れ、クリエイティブでは専用のグループにまとまっている。

## 動作環境

- Minecraft 統合版 **1.26.20 以上**(`format_version` / `min_engine_version` は 1.26.20。これより下げると動かない)
- Script API: `@minecraft/server` **2.0.0** / `@minecraft/server-ui` **2.0.0**(安定版だけ。実験機能の設定は不要)

### 同じワールドに入れられないアドオン

統合版では、ワールドに入っている全アドオンのブロックの「状態の組み合わせ数」の合計に **65,536** という上限がある。
このアドオンはワイヤーだけで 49,152、全体で約 56,000 を使う。
**同じ作者の「建材ブロック追加アドオン」とは、合計が上限を超えるので同じワールドに入れられない。**
ほかにもブロックの種類や状態が多いアドオンと組み合わせると上限を超えることがある。

## 入れ方

### .mcaddon を作って取り込む(おすすめ)

Python 3 が要る。

```
python tools/build_mcaddon.py
```

`dist/redstone_extensions.mcaddon` ができる。ダブルクリックすると Minecraft が開き、BP と RP がまとめて取り込まれる。
ワールドの設定で **ビヘイビアパックとリソースパックの両方**を有効にする。実験機能は不要。

すでに入れている版から入れ直すときは、`node tools/set_version.js <新しい版>` で版を上げてから作る。
同じ版のまま取り込むと、古いパックが残って「直したはずなのに直っていない」ことになる。

### フォルダを直接置く(開発向け)

`RedstoneExtBP` を `com.mojang/behavior_packs` へ、`RedstoneExtRP` を `com.mojang/resource_packs` へ写す。
`tools/deploy.ps1` は `%APPDATA%\Minecraft Bedrock\Users\Shared\games\com.mojang` へ写すスクリプト
(Minecraft を終了してから実行する。場所が違う環境ではスクリプトの中のパスを書き換える)。
`RedstoneExtBP/scripts/generate_wire_permutations.js` はビルド用のスクリプトで、パックには入れない。

## 開発

Node.js と Python 3(テクスチャを作り直すときは Pillow)を使う。

```
python tools/generate_textures.py      # テクスチャと terrain/item_texture.json(絵を変えたときだけ)
node tools/generate_wire_geometry.js   # ワイヤー/光源パネルのジオメトリ(形を変えたときだけ)
node tools/generate_blocks.js          # ブロック定義 RedstoneExtBP/blocks/*.json
node tools/set_version.js 1.31.4       # 版を全箇所まとめて書き換える
node tools/validate.js                 # 静的な検査
cd tools/harness && node test.mjs      # ゲーム外テスト
python tools/build_mcaddon.py          # .mcaddon を作る
```

- `RedstoneExtBP/blocks/*.json` とテクスチャは**生成物**。手で直さず、生成スクリプトの方を直す
- `tools/validate.js` は JSON の読み込み・テクスチャ/ジオメトリ/翻訳キーの参照・カスタムコンポーネントの登録・版の揃い・状態数の上限などを見る
- `tools/harness/` のテストは、自作の `@minecraft/server` スタブ(`tools/harness/node_modules/@minecraft/`)の上で `RedstoneExtBP/scripts` を動かす。
  スタブは自作なのでリポジトリに入れてある(`npm install` は不要)。テストは起動のたびに `RedstoneExtBP/scripts` を `tools/harness/scripts/` へ写す
- `tools/harness/profile.mjs` はスクリプトからゲームへの呼び出し回数を数える(重さの目安)

### 既知の制約

- 可変ディレイリピーターの待ち中のタイマーはメモリにしか無いので、ワールドを読み込み直すと一度リセットされる
- 循環した配線の自動停止は無い(発振したままになる)
- ワイヤーは 1 マスに 1 本まで。色違いのワイヤーを同じマスで交差させることはできない
- センサーと時刻トリガーの更新は 1 秒ごと
- ガイドブックとリモコンの画面の本文は日本語だけ(ブロック名・アイテム名・アクションバーの文は日本語と英語)
- 重さはブロックの数に比例する。ワイヤーを何百個も置くなら、一部をバニラのレッドストーンダストにすると軽くなる
